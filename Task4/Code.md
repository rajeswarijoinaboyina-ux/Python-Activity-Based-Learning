
# Employee Payroll and Deduction Analysis Using Python

## 1. Problem Statement

The Employee Payroll System calculates employee gross salary using basic pay, allowances, overtime, and incentives. It applies progressive deductions and generates a formatted salary statement showing gross salary, deductions, and net salary.

## 2. Algorithm

1. Start the program.
2. Enter employee details.
3. Enter basic pay, allowances, overtime, and incentives.
4. Calculate gross salary.
5. Apply progressive deductions.
6. Calculate net salary.
7. Generate salary statement.
8. Stop the program.

## 3. Flowchart Using Mermaid
``` mermaid
flowchart TD
 A([Start]) --> B[/Enter Employee Details/]
 B --> C[Calculate Gross Salary]
 C --> D[Apply Progressive Deductions]
 D --> E[Calculate Net Salary]
 E --> F[Generate Salary Statement]
 F --> G([Stop])


```

## 5. Sample Input
Enter employee name: Raju
Enter basic salary: 25000
Enter allowances: 5000
Enter overtime pay: 2000
Enter incentives: 3000

## 6. Sample Output
--- SALARY STATEMENT ---
Employee Name: Raju
Basic Salary: 25000.0
Gross Salary: 35000.0
Total Deduction: 2500.0
Net Salary: 32500.0
